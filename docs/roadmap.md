# Outcome roadmap

## Now — Reduce time to first useful insight

Fast search, comparable table, map context, explainable risk labels, secure registration/session flow and bounded company explanations.

## Next — Increase repeat research

Persist local-first saved companies to the authenticated account, migrate anonymous saves after login, add recently viewed companies, shareable workspace filters and richer verification provenance.

## Controlled rollout

Portfolio comparison is implemented behind `portfolioCompare` and uses up to three saved companies. The rollout stays disabled by default while the product hypothesis and metrics are evaluated.

## Later — Improve team decision quality

Workspace roles, annotations, export workflows, configurable risk policies and collaboration/audit features.

Prioritization favors user value × confidence ÷ effort, with security and accessibility treated as release criteria rather than optional backlog work.
